# Evidencias

El repositorio conserva cuatro evidencias gráficas relacionadas con la implementación SQL:

- E-02: estructura de tablas.
- E-04: entorno de ejecución.
- E-06: tipo de índice.
- E-10: tiempos de una ejecución histórica de COUNT(*) con 500 repeticiones. Sus valores son referenciales y no corresponden a los promedios formales documentados en EXP-01.

## Dashboard Power BI

El informe académico incluye las tres páginas del dashboard:

1. Viajes y Magnitudes por fecha y turno.
2. Indicadores de carga por turno.
3. Tendencias y Atípicos.

Estas páginas forman parte del informe académico. No se incluyen como archivos de imagen independientes en el repositorio.
